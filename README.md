*Este proyecto consiste en el desarrollo de una aplicación web para la gestión de categorías, incorporando un sistema de registro y autenticación de usuarios.* 

*La aplicación permite que cada usuario cree una cuenta, inicie sesión y administre sus propias categorías mediante las operaciones **CRUD (Crear, Consultar, Actualizar y Eliminar)**. El sistema utiliza una base de datos SQLite para almacenar la información y gestionar la relación entre los usuarios y sus respectivas categorías.*

# ***Objetivos***:
- Implementar un sistema de registro de usuarios.
- Incorporar autenticación para controlar el acceso a la aplicación.
- Permitir la creación, consulta, actualización y eliminación de categorías.
- Garantizar que cada usuario pueda administrar únicamente sus propias categorías.
-  Utilizar SQLite para almacenar y gestionar los datos.

# ***Funcionalidades***:
- Registro de usuarios.
- Permite crear una cuenta mediante nombre, correo electrónico y contraseña.
- Inicio de sesión.
- Permite autenticar a los usuarios registrados y acceder a sus categorías.
- Gestión de categorías (CRUD)- Crear: registrar nuevas categorías.
- Consultar: visualizar las categorías almacenadas.
- Actualizar: modificar la información de una categoría.
- Eliminar: borrar categorías existentes.
- Cada usuario administra exclusivamente sus propias categorías mediante la identificación de su sesión.
- Permite finalizar la sesión y salir del área privada de la aplicación.
